SmartMeter Blink controls the optical button of a Landis+Gyr/EYKON E320 smart meter using the phone's torch or screen light — no physical buttons, no PIN guessing.

Features:
- Predefined meter profiles loaded from app/src/main/assets/meter_profiles.json (JSON import/export compatible)
- Multiple saved profiles per meter model
- Torch and screen flash light sources
- English and German UI
- Quick actions: toggle the optical info interface (inF) and PIN protection (Pin)
- Import / export profiles as JSON (format 1)
