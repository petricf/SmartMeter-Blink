SmartMeter Blink
User Guide

Version 1.0 — App for Android (application id de.smartmeter.blink)

1. About the App

SmartMeter Blink turns the light of your phone into an optical remote control for a Landis+Gyr/EYKON E320 (or similar) smart electricity meter. The meter has an optical port and accepts button presses as short or long bursts of light. The app uses the camera torch or a full-white screen flash to send the 4-digit PIN of the meter and to toggle settings such as the optical info interface (inF) and the PIN protection (Pin) — without touching the meter's physical buttons.

Included in this guide (German version: Benutzerhandbuch.pdf).

2. Safety First

⚠ Warning — data loss. Only a long flash (>5 s) actually presses the "hold" button of the meter and can trigger an action. A long flash erases stored values when the meter currently shows E, E CLr, 1d, 7d, 30d, 365d or HiS CLr. Long flashes are only safe on the displays P, inF and Pin. Always start every action from the P (power) display.
⚠ Legal notice — misuse. This app and its source code may only be used on meters you own or are authorized to operate. Using or modifying the app or its source code to obtain a meter’s PIN by brute force, or to otherwise gain unauthorized access to a meter, is not permitted.
Tip: Hold the phone's light against the meter's optical button/port instead of the display, keep it steady, and do not move it until the sequence has finished.

3. Installation

  1. Install the SmartMeter-Blink.apk on the phone (Share or copy the file and open it; allow "install unknown apps" when asked).
  2. Start SmartMeter Blink. On first launch the app asks for the Camera permission — this is needed to use the torch. Grant it, or the app automatically falls back to the screen flash.
  3. Optionally verify the signal by pressing Test light: the torch or screen should light up for about two seconds.

The app needs two permissions: Camera (torch) and Vibrate (feedback during flashes). No other data is collected; everything stays on the device.

4. Quick Start

  1. Open the app — the profile Landis+Gyr/EYKON E320 is active by default.
  2. Chose the light source: Torch or Screen.
  3. Enter your meter PIN on the keypad (the meter's 4-digit display test code).
  4. Hold the phone so the light aims at the meter's optical port.
  5. Press Send PIN. A 3-second countdown starts, then the app wakes the meter with a short pulse and sends the PIN digit by digit.
  6. Keep the phone steady. A progress bar shows the remaining time.
  7. When the meter leaves the PIN prompt, you are in the menu. Use Short pulses to scroll and a Long pulse to act — or let the app do it for you with Quick Actions (section 7).

5. How the Optical Interface Works

Meter buttons are triggered by light. One short flash equals one short button press, a long flash (5–6 s) equals keeping the button pressed.

  • When the meter is idle it shows the power display (P). One short flash wakes it into the display test (all segments, about 4 s), then the PIN prompt.
  • Each PIN digit is sent as that many short flashes: 1 → one flash, 2 → two flashes, …, 9 → nine flashes, 0 → no flash (the app simply waits).
  • After each digit (except the last) the app waits ~3.4 s so the meter can accept the digit (its timeout is ~3 s).
  • After the last digit the meter unlocks into the service menu.

Menu after unlock

6. Screen Tour

Meter profile

Shows the active profile (default Landis+Gyr/EYKON E320) and its description. Tap the button next to "Meter" to open the profile menu: select another profile, ＋ New profile (copy current), Export current profile…, Export all profiles…, Import from JSON… and Delete current profile.

Light source

Torch uses the camera LED; it only works if the device has a flash and the Camera permission is granted. Screen flashes the whole display white and works on every device. Test light lights the chosen source for ~2 s.

Darken screen during sequence

During a run the screen turns black and only shows the progress (ideal in the dark). You can stop the sequence by tapping anywhere.

PIN entry

Keypad with digits, backspace and clear. The required PIN length (default 4, configurable 1–8) is shown by the number of boxes. During a run the currently-transmitted digit is highlighted.

Send PIN / Stop

Send PIN starts the full sequence (only enabled when the PIN is complete). While running, the same button becomes Stop.

Progress bar

Shows how far the sequence is and an estimate such as ~42s left.

Quick actions

Two cards automate the menu walk: Optical interface (inF) and PIN requirement (Pin). Each card has a per-run switch "Send PIN first (meter asks for PIN)":

  • On (default): the app sends the PIN, then scrolls to the item and holds the long flash to toggle it.
  • Off: the PIN phase is skipped and only the menu steps are sent. Use this when the meter shows Pin oFF — with PIN disabled every flash scrolls the menu, so sending PIN digits would walk past your target (the app warns about this).

The line "Steps after PIN: N" shows how many scroll steps the profile uses for that action (edit under Settings). If the PIN is required but not yet entered, a dialog asks for it first.

Manual pulses

Short = one menu step; Long = hold (toggle an item). Useful when you want to scroll yourself; remember the safety warning, never long-flash a CLr display.

Screen orientation

The app also works in landscape orientation: simply rotate the phone. The content scrolls vertically, so nothing is cut off.

Settings

  • Wake with display test first — a single short pulse first, then a wait (4 s) so a sleeping meter enters the display test. Used by Send PIN and the quick actions.
  • PIN length — 1 to 8 digits.
  • Timing sliders — pulse length (100–400 ms), pulse gap (100–600 ms), digit wait (2.0–5.0 s), long pulse (4.0–9.0 s).
  • Steps to inF / Steps to Pin — how many menu steps the quick actions walk (0–16).

7. Profiles and JSON Export/Import

All timings and step counts are stored per profile, so you can tweak them for a different meter model and keep multiple presets.

  • ＋ New profile (copy current) — duplicates the active profile so you can experiment without touching the original.
  • Export current / Export all — writes the profile(s) to a JSON file (Suggested location).
  • Import from JSON… — reads a JSON file; profiles with an already-known id are updated, new ids are added, invalid entries are skipped.
Example JSON:
[ { "format": 1,
    "id": "e320", "name": "Landis+Gyr/EYKON E320", "pinLength": 4,
    "pulseLengthMs": 180, "pulseGapMs": 320, "digitWaitMs": 3400, "longPulseMs": 6000,
    "opticalScrolls": 8, "pinScrolls": 9,
    "description": "Standard meter. Menu: P → E → E CLr → 1d → 7d → 30d → 365d → HiS CLr → inF → Pin." } ]

9. Troubleshooting

ProblemSolution
Torch does not switch onGrant the Camera permission (app start or Android app settings). The app shows the reason in red. Some devices reject the torch while another app uses the camera — close it.
"No torch on this device"The phone has no flash camera. Use the Screen light source instead.
Meter does not wake / no responseHold the light exactly on the optical port, keep it steady, and make sure "Wake with display test first" is on. Increase the pulse gap in Settings if the meter rejects flashes.
Sequence finishes but the meter did not unlockAim better and/or increase the digit wait. Ensure you entered the correct PIN.
Meter shows Pin oFF and the menu jumps past the targetSwitch "Send PIN first" off for the quick action.
App languageThe app follows the phone's display language: German phone → German UI, otherwise English.

10. Removing the app

Long-press the app icon → Uninstall. All profiles and settings are stored only on the device and are removed with the app, unless you exported them to a JSON file first.
